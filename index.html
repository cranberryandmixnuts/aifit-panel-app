    여기서 만든 프로필은 연동한 모든 게임에 같은 이름으로 생겨요. 프로필을 만들고 지우는 건 이 앱에서만 해요. 게임에서 만든 프로필은 그 게임에만 있어요.

      연동한 게임

        연동하는 법

        1. 게임의 설정 화면에서 태블릿 연동 → 연동 번호 받기를 눌러요.
        2. 이 앱에서 게임 연동하기를 누르고 게임 화면의 QR을 찍으면 바로 연동돼요.
        3. 카메라를 못 쓰면 8자리 번호를 넣고, 두 화면의 확인 번호 4자리가 같을 때 게임에서 연동을 눌러요.

        두 기기가 인터넷에 연결돼 있거나 같은 공유기에 있으면 돼요. 기록과 설정은 게임이 켜져 있을 때 받아 와요. 여기서 고른 언어는 연동한 게임에도 같이 적용돼요.

        게임 연동하기

        이 주소에서는 카메라를 쓸 수 없어요. 아래에 번호를 넣어 주세요.

        게임 화면의 연동 QR을 네모 안에 비춰 주세요.

        또는 번호로

        인터넷이 안 될 때 (같은 공유기)

        게임 설정의 태블릿 연동 아래에 나오는 같은 공유기 주소를 넣어요.

        웹 주소에서는 인터넷 중계로만 연결돼요. 게임 PC도 인터넷에 있어야 해요. 같은 공유기 직접 연결은 설치형 앱이나 게임 PC의 '이 컴퓨터에서 앱 열기'로 해요.
