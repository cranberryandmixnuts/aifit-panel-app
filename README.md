# AI FIT 연동 (태블릿 앱, 웹판)

AI FIT 세 게임(리듬 트레이닝, 정글 보물 탐험대, 3D 움직임놀이)의 선생님용 태블릿 앱을 브라우저로 쓰는 판입니다. 안드로이드 APK와 같은 코드이고, 연동 모듈 0.17.0이 들어 있습니다.

- 주소: https://cranberryandmixnuts.github.io/aifit-panel-app/
- 이 웹 주소(https)에서는 **인터넷 중계로만** 게임과 연결됩니다. 게임 PC와 이 브라우저가 모두 인터넷에 있으면 됩니다. 같은 공유기 직접 연결은 브라우저가 막으므로(https → http 혼합 콘텐츠) 설치형 앱이나 게임 PC의 `이 컴퓨터에서 앱 열기`를 씁니다.
- 연동 열쇠와 받은 기록은 이 브라우저의 저장소(localStorage)에만 남습니다. 서버는 없습니다. 브라우저 데이터를 지우면 연동이 풀립니다.
- 이 저장소는 빌드 결과만 담습니다. 원본은 AI FIT 리듬 트레이닝 저장소(비공개)의 `mobile/www`·`src/panel`이고, `npm run web-app:publish`로 여기에 올립니다. 마지막 원본 커밋: 96fbbea.
